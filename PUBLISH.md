# Комплект ABarz 1.9.10

- `autoabarz.lua` — с обновлением самого скрипта.
- `abarz1.6.lua` — без обновления самого скрипта, с той же функциональностью.
- `version.json` — версия 1.9.10 для загрузчика.
- `lib` — семь автоматически скачиваемых библиотек ABarz.
- `arizona-events` — копия для загрузчиков старых версий.
- `images` — логотип и оформление репозитория.
- `packages/BLAST_CHANGELOG.txt` — локальный текст для форума с BBCode, вне Git.
- `packages` — ZIP-комплекты и контрольные суммы для вложений GitHub Release; папка исключена из Git.
- `mooloader.zip` — комплект ABarz 1.6 с правильной папкой `moonloader` внутри.

## Установка

Можно скачать один Lua-файл: обе сборки автоматически скачивают notifications, CEF-диалоги, четыре файла arizona-events и мост Arizona Market. Логотип также скачивается автоматически. Устанавливать обе сборки одновременно нельзя.

В ZIP-комплектах уже лежат выбранный скрипт, все семь библиотек и логотип. Настройки и базы создаются при работе, личные данные в архивы не включаются.

MoonLoader, mimgui, effil, SAMP.Lua и стандартные библиотеки сборки должны быть установлены отдельно. ABarz не устанавливает сам MoonLoader.

Иконки и их декодер встроены в основной Lua. Отдельные PNG, abarz-webp.lua и подготовленный индекс не нужны: игровые изображения читаются из установленного arizona/items.zip при просмотре и остаются в памяти.

## Arizona Market

Если установлен оригинальный скомпилированный `#ArzMarket[3_57].lua`, мост подключается автоматически. Оригинал сохраняется в `ArzMarket/abarz-bridge`, а уже загруженный Arizona Market перезагружается для подключения. Повторного изменения уже установленного загрузчика нет. При изменении оригинального байткода прежняя копия сохраняется, новая получает отдельное имя.

Если Arizona Market отсутствует, остальные функции ABarz работают. Сам Arizona Market не скачивается. Другие версии и неизвестные пользовательские исходники автоматически не заменяются.

После подключения откройте `/crr` и выберите маркетплейс Vice City. Мост сохраняет штатно полученные данные лавок и вызывает штатное обновление раз в пять минут. Эти обновления используют API Arizona Market. ABarz не читает токен и не выполняет собственные запросы к этому API.

## Публикация

В релиз `v1.9.10` приложить оба Lua-файла, ZIP-комплекты, mooloader.zip и SHA256SUMS.txt. README содержит ссылки на загрузку из последнего релиза.

В комплект не включены личные настройки, сделки, базы цен, логи, токены, конфигурация устройства Cloudflare, административный доступ и оригинальный байткод Arizona Market.
