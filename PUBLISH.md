# Комплект ABarz 1.9.9

В корне — файлы репозитория для GitHub. Папка `packages` содержит готовые комплекты для установки; она исключена из Git и предназначена для вложений GitHub Release / форума.

## Файлы обновления

- `autoabarz.lua` — с проверкой и обновлением самого скрипта.
- `abarz1.6.lua` — без обновления самого скрипта, с той же функциональностью.
- `version.json` — новая версия 1.9.9 для загрузчика.
- `lib`, `arizona-events`, `images`, `tools`, README и changelog для форума — сопровождающие файлы.

В релиз `v1.9.9` нужно приложить оба Lua-файла и архивы из `packages`. Кнопки README скачивают Lua-файлы из последнего GitHub Release. До публикации нового релиза они ведут на предыдущую версию.

## Что включено в архивы

В каждом архиве папка `moonloader` с ОДНОЙ версией ABarz, шестью основными библиотеками, отдельным мостом Arizona Market, логотипом и необязательным установщиком моста. Устанавливать обе версии одновременно не нужно.

Декодер иконок и чтение игрового архива встроены в Lua. Отдельные `abarz-webp.lua`, индекс иконок и папка распакованных картинок не нужны. Изображения читаются по мере просмотра из `arizona/items.zip` установленной игры и декодируются средствами Windows.

## Необязательные цены Arizona Market

Для цен деталей из VC нужен установленный Arizona Market 3.57 и мост. Сам Arizona Market и его оригинальный байткод в комплект не включены.

1. Скопировать содержимое выбранного архива в игру.
2. Закрыть игру. Для подключения моста запустить `moonloader/tools/Install-ArzMarketBridge.cmd`. Установщик сохраняет оригинальный Arizona Market и добавляет загрузку отдельного `lib/abarz-market-bridge.lua`.
3. В игре открыть `/crr`, выбрать маркетплейс Vice City и дождаться загрузки.

Если мост уже подключён, повторная установка не нужна. При обновлении Arizona Market может потребоваться повторное подключение. Установщик рассчитан на оригинальный скомпилированный файл `#ArzMarket[3_57].lua`.

Мост вызывает штатное обновление Arizona Market раз в пять минут после получения списка VC. Штатные запросы используют API Arizona Market; отсутствие риска блокировки токена не гарантируется. ABarz напрямую токен не читает и отдельные запросы к этому API не отправляет.

## Проверки и публикация

Обе сборки компилируются; проведены локальные проверки выставления, снятия и повторного выставления лотов, качества, цен и иконок. Автоматические проверки не заменяют контрольную проверку в игре на обычном сервере и Vice City.

В комплект не включены личные настройки, сделки, цены, логи, токены, конфигурация устройства Cloudflare, административный доступ и пользовательские оригиналы Arizona Market. Комплект предназначен для публикации на GitHub и Blast.hk.

Файл `mooloader.zip` в корне — готовый комплект ABarz 1.6; внутри используется правильная папка `moonloader`. Текст для форума: `docs/BLAST_CHANGELOG.txt`.
