- При выборе сервера маркетплейс загружается приоритетно, без ожидания общего 30-секундного интервала. Между запросами сохраняется минимальный интервал 2 секунды.
- Кнопка «Обновить каталог» повышает приоритет ожидающего запроса. Старые запросы предыдущих серверов удаляются из очереди.
- Во время загрузки показывается соответствующая надпись; выбор другого сервера переключает фильтр на «Все лоты».
- Фоновое обновление по-прежнему выполняется раз в 30 секунд.
- Обновлены обе сборки. Файлы `abarz1.5.lua` и `abarz1.4.lua` содержат одинаковую версию без автообновления; устанавливайте только один скрипт.

# ABarz 1.9.3 — 19.11.2026

- Исправлено преждевременное завершение сканирования после первой страницы, в том числе при сокращённой надписи «След. страница».
- Переход выполняется по найденной строке навигации: скрипт больше не нажимает строку №2 наугад.
- Увеличено ожидание ответа при переходе между страницами. При сбое появляется предупреждение, уже считанные цены сохраняются.
- Страницы сравниваются по всему списку моделей, поэтому совпадение первой машины больше не прерывает сканирование.
- Увеличен защитный предел с 40 до 1000 страниц; скан заканчивается при достижении конца списка или повторе уже обработанной страницы.
- Исправление включено в обе сборки: с автообновлением и без него.

Проверено на тестовом каталоге из 430 моделей, отдельно — на каталоге из 46 страниц.

# ABarz 1.9.2 — 19.11.2026

Крупное обновление: маркетплейс транспорта, графики цен и новый сервис для обмена данными.

## Маркетплейс

- Добавлен общий каталог машин игроков, использующих ABarz. Теперь можно посмотреть предложения, не приезжая на автобазар.
- Лоты публикуются автоматически при выставлении машины на продажу.
- Добавлен выбор сервера. Vice City находится первым в списке; предложения разных серверов разделены.
- В объявлении отображаются модель, цена, продавец, наличие Twin Turbo и доступные сведения о тюнинге. На обычных серверах доступно сравнение с собственной базой средних цен.
- Добавлено автоматическое считывание тюнинга перед выставлением машины: скрипт открывает инвентарь и вкладку автомобиля, затем продолжает выставление.
- Исправлен пропуск технических и визуальных деталей при первом открытии инвентаря. Готовые данные принимаются сразу, без повторного запроса вкладки и лишнего ожидания.
- Список установленного тюнинга свёрнут по умолчанию: в объявлении виден заголовок с количеством деталей, полный список раскрывается по нажатию.
- Переработан внешний вид объявлений: широкий список лотов, информация справа, компактная фотография машины с увеличением при наведении.
- Исправлены повторяющиеся объявления при перестановке машины и перезагрузке скрипта.
- Исправлено удаление объявлений при ручном снятии и продаже. Неактивные объявления автоматически исключаются из каталога.
- Исправлена ошибка `invalid_tuning`, из-за которой машина могла не появляться у других игроков.

## Цены и серверы

- Для каждого сервера используется отдельный файл средних цен. Сканирование на другом сервере больше не перезаписывает основную базу.
- Исправлено определение сервера при подключении через домен или числовой IP: оба адреса ведут в один чат и каталог.
- Добавлена история цен автомобиля: таблица по дням, количество продаж и график изменения средней цены.
- Обновлено отображение фотографий автомобилей; добавлен альтернативный источник изображений.
- Добавлена поддержка отличающихся табличек Vice City. Системные средние цены обычных серверов к Vice City не применяются.
- Обмен базами учитывает сервер: чужая база не импортируется в базу другого сервера, а скачивание отменяется при смене сервера.

## Чат и обмен данными

- Чат, маркетплейс и обмен базами полностью перенесены с ntfy на Cloudflare Workers + D1.
- Повторная отправка сообщений и лотов не создаёт дубли.
- Базой цен можно поделиться через чат ABarz; у сообщения появляется кнопка скачивания.
- Чат открывается только по команде `/abchat` или назначенному бинду.
- Убрана лишняя сетевая диагностика из консоли и команда `/abnet`.

## Интерфейс и сборки

- Исправлена работа мыши: вкладки, кнопки и объявления снова реагируют на нажатия.
- Сохранено управление персонажем при открытом меню.
- Подготовлены две сборки с одинаковыми функциями: `autoabarz.lua` с обновлением скрипта и `abarz1.4.lua` без него. Обе имеют версию 1.9.2.
- Убраны остатки локальной тестовой сборки. В версии с обновлениями снова работает проверка GitHub; её настройка сохраняется.

Устанавливайте только одну сборку. Для общего чата и маркетплейса всем участникам нужна актуальная версия ABarz.
